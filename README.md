# StrandedDeep_SDMap
# SDMap — Stranded Deep 地图模组

给 **Stranded Deep** 增加小地图与可缩放大地图的 BepInEx 模组。支持多种渲染方式、路径点（标记点）管理、世界内光柱标记，并兼容多人联机（MultiplayerPlus）的路径点分享。

> **⚠️ 特别注明**：本模组全部代码由 **DeepSeek V4 Pro** 生成；**Chengxidaxia负责测试与调试**。

## 功能特性

- **小地图**：屏幕角落常驻的小地图，实时显示玩家朝向（箭头）、路径点、坐标（X/Y/Z）与联机队友位置。
- **大地图**：按 `M` 键打开的全屏大地图，滚轮缩放、鼠标拖拽平移、右键添加路径点、点击路径点传送（可选）。
- **多种渲染方式**：
  - `Legacy`：高度图彩色分层纹理，性能最好。
  - `VirtualCamera`（默认）：虚拟摄像机实时渲染，画面接近玩家视角的精细度。
  - `Shader`：GPU 着色渲染（高程分层 + 法线光照，立体浮雕）。
  - 实验性「其他渲染」：`SoilMap`（真实土壤分布）、`Nlight`（法线光照）、`Steepness`（坡度着色）、`NLLayer`（分层设色+光照）、`TileMap`（超高分辨率）、`TMCache`（超高分辨率+快照缓存）。
- **正交 / 透视相机可选**：默认透视投影（画面中心高 LOD、接近玩家视角），可切换正交投影（全图均匀精度）。
- **路径点（标记点）**：
  - 世界坐标记录，添加时自动计算「最高可站立层」高度（海里则记海平面）。
  - 8 种颜色可选、可改名、可删除、可传送。
  - **世界内光柱**：路径点在玩家第一人称视角渲染成一条竖直光柱（颜色 = 路径点颜色）+ 顶部名称，帮你在世界里找到目标。
  - 随游戏存档自动保存/读取（不再使用独立 JSON 文件）。
- **多人联机（MP）分享**：安装了 MultiplayerPlus 并处于联机时，可一键把路径点完整信息（名称+坐标+颜色）分享给队友。

## 安装

1. 确保已安装 **BepInEx**（BepInEx.New 目录）。
2. 将 `SDMap.dll` 放入 `{BeplnEx}\plugins\SDMap\`。
3. 启动游戏，进入存档后按 `M` 打开大地图验证。

## 使用说明

| 操作 | 说明 |
|------|------|
| `M` | 打开 / 关闭大地图 |
| 滚轮 | 缩放大地图（越大越近越精细，1 = 显示整个世界） |
| 鼠标拖拽 | 平移大地图 |
| 右键地图 | 在点击位置添加路径点（弹出菜单） |
| 左键路径点 | 传送（需在配置里开启「允许传送」） |
| `ESC` | 关闭大地图 |

**路径点列表**（大地图下方）提供每项操作：改色（点颜色块）、分享（MP）、改名、删除、传送。

## 多人联机（MultiplayerPlus）路径点分享

- 前提：**所有联机玩家都安装了 SDMap 与 MultiplayerPlus**（否则消息类型集合不一致会导致同步错位）。
- 在路径点列表点「分享」，即可把该路径点的**名称、坐标、高度、颜色**一次性打包发给队友；队友同坐标会覆盖更新，否则新增。
- 路径点数据随**房主存档**保存，读档后所有玩家自动恢复。

## 技术说明

- 小地图 / 大地图渲染：`Legacy` 用高度图彩色分层纹理；`VirtualCamera` 用虚拟摄像机（正交/透视可选）实时渲染，渲染前临时调低地形 `heightmapPixelError`、拉高 `basemapDistance` 以获得接近玩家视角的精细度。
- 路径点世界内光柱：每个路径点一个 `LineRenderer` 光柱（`Sprites/Default` 材质 + 顶点色）+ 顶部 `TextMesh` 名称（billboard 朝向玩家），放在 Default 层以避开地图相机的 cullingMask。
- 路径点持久化：实现游戏原生 `IPersistentSaveable`，随存档自动保存到 `Persistent.SDMapWaypointStorage` 并读档恢复。
- 路径点多人分享：继承游戏原生 `MultiplayerMessage`，`[Replicate]` 字段序列化 + `Post()` 广播，接收方按坐标 upsert。
